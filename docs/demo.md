# Local ERC-4337 execution

`make verify-phase4` creates disposable PostgreSQL 18 and Anvil instances and runs two independent paths: direct `EntryPoint.handleOps` and `eth_sendUserOperation` through pinned Alto. Both paths use the Phase 1 normalized account call, Phase 2 durable reservation, Phase 3 issued artifact, and `internal/userop` builder. The account owner separately signs EntryPoint's `getUserOpHash` result. The account begins and ends with zero native balance.

The direct path compiles the pinned v0.9 EntryPoint source and deploys it at a fresh local address. The external path uses Alto's pinned v0.9 deterministic deployment transaction to deploy EntryPoint at the official singleton address on Anvil. The verifier checks the measured runtime code hash against the pinned local fixture value `0x94c969b899cb2a68ac9c124d8ee104a047771ee988f155b4e4683c254291f805`. [ADR 0004](adr/0004-local-entrypoint-deployment.md) explains why the two paths use different local addresses.

The test deploys `DemoAccount`, `DemoCounter`, and `PolicyPaymaster`; funds a one-ether paymaster deposit in EntryPoint; creates an allowed `execute(address,uint256,bytes)` request; reserves capacity; issues its authorization; and sends one complete PackedUserOperation. The target count becomes one. `UserOperationEvent` identifies the sender and paymaster and reports success and actual gas cost. The paymaster deposit decreases by that same amount. An exact second submission fails at EntryPoint nonce validation. A modified account calldata payload with a fresh owner signature fails sponsor validation.

`build/local-deployment.json` records chain ID, contract addresses, runtime EntryPoint code hash, transaction hashes, source revisions, policy version, sponsorship and UserOperation IDs, account balances, deposit balances, actual gas cost, and settled PostgreSQL hold/spend. The file is ignored because a fresh local run replaces it.

Alto is a separate process loaded from the checksum-checked source snapshot recorded in `dependency-snapshots/manifest.json`, based on upstream commit `96529592b67a69be23c013359cbc9990657af64a`. The verifier installs its locked dependencies with pnpm 8.15.4 and builds its simulation contracts on first use. Its deterministic local development accounts are loaded from its pinned test fixture into a temporary configuration; local `safe-mode` is disabled, so the test does not prove ERC-7562 mempool admission. No bundler key is part of the policy service. The external RPC request carries `paymasterData` and `paymasterSignature` separately; Alto packs them into the exact 243-byte v0.9 `paymasterAndData` validated by the contract.

The Phase 5 path scans the chain through HTTP, observes the event while the reservation remains held, mines to three local confirmations, and settles the exact event cost in PostgreSQL. `scripts/verify_phase5.py` also runs a reverted target call, an authorization that is never submitted, an unknown/no-inclusion scenario, and an Alto submission whose HTTP response is deliberately dropped after the bundler accepted the call. The deterministic PostgreSQL fork fixture covers orphaning, reinclusion, deep reorg, two workers, and terminal contradictions.

`make demo` runs the final local path. It starts the real sponsorship HTTP handler with the same admission, issuance, signer, store, and watcher components as the local service. It verifies a 201 approval and identical 200 retry, 409 changed-key conflict, 422 disallowed target, Alto submission, paymaster/account validation, final exact-cost consumption, scoped GET state, status and metrics, and a second signed authorization that expires unused after confirmed chain-time coverage. It asserts three requests, two reservations, one consumed record, one expired unused reservation, zero open holds, a zero-balance account, one target increment, deposit delta equal to `actualGasCost`, and a SHA-256 checksum of the exact integer accounting statement. `scripts/verify_phase6.py` checks the ignored local metadata. Public-chain deployment and production signer custody remain outside this implementation.
